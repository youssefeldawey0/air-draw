# ✍️ Air Draw — draw with your finger using MediaPipe + Streamlit

Point your webcam at your hand and draw in the air with your index finger.
Hand tracking is done by [MediaPipe Hands](https://developers.google.com/mediapipe), the UI is a [Streamlit](https://streamlit.io) app, and the webcam stream runs in the browser via `streamlit-webrtc`.

## Project structure

```
hand-drawing-app/
├── app.py               # Streamlit app (webcam + controls)
├── hand_drawing.py      # Hand-tracking/drawing engine (generated by the notebook)
├── hand_tracking.ipynb  # Jupyter notebook with the MediaPipe code + local demo
├── requirements.txt
└── README.md
```

## Setup

Use Python **3.9 – 3.12** (MediaPipe's legacy `solutions` API is used). On Windows, Python 3.11 is a known compatible choice:

```powershell
py -3.11 -m venv .venv311
.\.venv311\Scripts\Activate.ps1
python --version
python -m pip install -r requirements.txt
```

On macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run the Streamlit app

On Windows, from the project folder, run the app with the project virtual environment explicitly. Port `8502` avoids showing another Streamlit project that may already be using the default port:

```powershell
Set-Location "D:\Downloads\hand-drawing-app\hand-drawing-app"
.\.venv311\Scripts\python.exe -m streamlit run .\app.py --server.port 8502
```

Open the URL printed by Streamlit (usually http://localhost:8502). On macOS/Linux, activate the virtual environment, then run:

```bash
python -m streamlit run app.py
```

Click **START** and allow camera access.

## Run / edit the notebook

```bash
jupyter notebook hand_tracking.ipynb
```

- The `%%writefile hand_drawing.py` cell exports the engine to `hand_drawing.py`, which `app.py` imports. Edit the notebook, re-run that cell, and the app picks up the changes.
- The demo cell opens a local OpenCV window (`q` quit, `c` clear, `s` save PNG).

## Gestures

Keep your hand upright, palm facing the camera, in decent light.

| Gesture | Action |
|---|---|
| ☝️ Index finger only | Draw |
| ✌️ Index + middle | Hover (move without drawing) |
| 🤟 Index + middle + ring | Eraser |
| 🖐️ Open palm, hold ~1 s | Clear canvas |

The sidebar lets you change colour, thickness, smoothing, toggle the hand skeleton, clear, and capture/download your drawing as a PNG.

## Troubleshooting

- **Camera doesn't start / stuck on "loading"** – allow camera permission in the browser and close other apps using the camera. Behind strict firewalls/VPNs, WebRTC may need a TURN server.
- **MediaPipe installation reports no matching version for `mediapipe<=0.10.21`** – check `python --version`. Python 3.13+ is not supported by the pinned MediaPipe release; create and activate an environment with Python 3.9–3.12 using the setup steps above.
- **`OSError: [Errno 28] No space left on device` during installation** – pip may need temporary space on the system drive even when the project is on another drive. Check free space with `Get-PSDrive -PSProvider FileSystem`. On Windows, you can use a drive with more free space for temporary downloads and disable pip's cache:

  ```powershell
  New-Item -ItemType Directory -Force D:\pip-temp | Out-Null
  $env:TEMP = 'D:\pip-temp'
  $env:TMP = $env:TEMP
  .\.venv311\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
  ```

  Replace `D:\pip-temp` with a path on a drive that has enough free space. Alternatively, `py -3.11 -m pip cache purge` removes pip's cached downloads.
- **`module 'mediapipe' has no attribute 'solutions'`** – this app requires the legacy MediaPipe `solutions` API. Install from `requirements.txt` in a supported Python environment.
- **Shaky lines** – raise *Smoothing* in the sidebar. **Laggy lines** – lower it.
- **Hand not detected** – improve lighting and keep your whole hand in frame.
